# SmallBusinessFinance

**Веб-приложение для учёта финансов малых предприятий**

## О проекте

SmallBusinessFinance — прототип веб-приложения, предназначенного для учёта и анализа финансовых операций малого предприятия. Приложение позволяет регистрировать доходы и расходы, управлять финансовыми счетами и категориями операций, просматривать сводные показатели и формировать финансовую отчётность.

Проект разработан в рамках выпускной квалификационной работы по направлению «Прикладная информатика», профиль «Инжиниринг предприятий и информационных систем».

## Основные возможности

- **Учёт финансовых операций:** хранение сведений о доходах и расходах, их суммах, датах, счетах и категориях.
- **Управление счетами:** создание и ведение расчётных счетов, касс и других счетов предприятия.
- **Управление категориями:** разделение операций на доходы и расходы.
- **Главная панель:** отображение основных финансовых показателей, количества активных счетов и категорий, последних операций.
- **Финансовая отчётность:** просмотр совокупных доходов, расходов и финансового результата.
- **Графический анализ:** сравнение доходов и расходов по месяцам, динамика финансового результата и круговая диаграмма соотношения доходов и расходов.
- **Отчётность по категориям:** анализ распределения доходов и расходов по соответствующим категориям.
- **Административная панель:** управление данными приложения средствами Django Admin.

## Требования

Для запуска проекта необходимы:

- Python 3.10 или новее.
- Установленный пакетный менеджер pip.
- Веб-браузер.
- Подключение к интернету для загрузки библиотеки Chart.js с CDN.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <URL-репозитория>
cd SmallBusinessFinance
```

Вместо `<URL-репозитория>` укажите адрес репозитория.

### 2. Создание виртуального окружения

Если виртуальное окружение `venv` ещё не создано, выполните в терминале VS Code из корневой папки проекта:

```bash
python -m venv venv
```

### 3. Активация виртуального окружения

**Windows, терминал PowerShell в VS Code:**

```powershell
.\venv\Scripts\Activate.ps1
```

**Windows, терминал Command Prompt:**

```bat
venv\Scripts\activate.bat
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 5. Переход к Django-проекту

```bash
cd config
```

Команды Django далее выполняются из каталога `config`, в котором находится `manage.py`.

### 6. Применение миграций

```bash
python manage.py migrate
```

### 7. Проверка проекта

```bash
python manage.py check
```

### 8. Запуск веб-сервера

```bash
python manage.py runserver
```

После запуска приложение доступно по адресу:

http://127.0.0.1:8000/

Административная панель Django доступна по адресу:

http://127.0.0.1:8000/admin/

Для входа в административную панель необходимо создать учётную запись администратора:

```bash
python manage.py createsuperuser
```

## База данных

В прототипе используется SQLite. Доступ к данным осуществляется через ORM Django. Основные сущности предметной области:

- **Category** — категория дохода или расхода.
- **Account** — финансовый счёт предприятия.
- **Transaction** — финансовая операция.

Для изменения структуры базы данных используются миграции Django.

## Расчёт финансового результата

Финансовый результат за выбранный период определяется как разница между суммой доходов и суммой расходов:

**Финансовый результат = Доходы − Расходы**

Положительный результат означает превышение доходов над расходами, отрицательный — превышение расходов над доходами.
